# Scientific computing — MATLAB to Python portsCoursework from the Scientific Computing course (Institut d'Optique Graduate School, M1), ported from MATLAB to Python/NumPy. Original MATLAB code is kept alongside for comparison.| Folder | Topic | Methods ||---|---|---|| `lw_05_mauna_loa` | Keeling curve (atmospheric CO₂, Mauna Loa, 1958–2024) | Linear least squares, out-of-sample validation |## Highlights — `lw_05_mauna_loa`- Python matches MATLAB to 4 decimals (689.19 ppm projected for 2100), despite different solvers (SVD vs QR).- Adding an annual sinusoid to the quadratic trend cuts RMSE from 2.23 to 0.97 ppm; seasonal amplitude ≈ 2.8 ppm.- Out-of-sample test (fit before 2016, test 2016–2024): RMSE rises from 0.92 to 1.97 ppm — long-range extrapolation is unreliable.- Remaining residuals show multi-year swings (plausibly ENSO, Pinatubo) not captured by the model.## Run```bashuv syncuv run python lw_05_mauna_loa/mauna_loa.py```
